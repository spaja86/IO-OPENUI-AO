# Project Documentation for IO-OPENUI-AO

## Quick Start
To get started with IO-OPENUI-AO, clone the repository and install the dependencies:

```bash
git clone https://github.com/spaja86/IO-OPENUI-AO.git
cd IO-OPENUI-AO
npm install
```

## Prerequisites 
- Node.js (version >= 14)
- npm (version >= 6)

## Installation Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/spaja86/IO-OPENUI-AO.git
   ```
2. Navigate to the project directory:
   ```bash
   cd IO-OPENUI-AO
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```

## Available Scripts
In the project directory, you can run:
- `npm start` to start the application.
- `npm test` to run the test suite.
